# 雅思词汇复习 Web App（IELTS Vocab）

基于《雅思词汇真经》（刘洪波）全部 22 章词汇制作的离线复习工具。成品是**单个 HTML 文件**：双击即用、零依赖、完全离线，手机上也可以直接用浏览器打开。

## 功能特性

- **22 章完整词汇**：自然地理、植物研究、动物保护……身心健康、时间日期，共约 1100 词
- **单文件成品**：`ielts-vocab.html`（约 270KB）内嵌全部数据与样式，无需服务器
- **复习交互**：按章浏览、词义对照、进度记录等（以页面实际功能为准）
- **可重建**：词汇数据与页面均由 Python 脚本生成，数据可迭代、可再生成

## 使用方法

直接双击打开 `ielts-vocab.html`，或：

```bash
open ielts-vocab.html
```

## 构建链（如需修改词汇后重新生成）

```
词汇原文 → parse_vocab.py（解析为结构化 JSON）
        → build_vocab_app.py（生成 vocab_data.js 数据文件）
        → generate_html.py（生成单文件 ielts-vocab.html）
```

> 注：脚本中的输入/输出路径写的是最初的工作目录，重新运行时请先按当前目录调整路径。

## 项目亮点

- 「AI 辅助整理 → 一键生成离线工具」的完整流水线：把一本书的内容变成随身可用的复习 App
- 单文件架构刻意为之：零安装、零部署，任何设备浏览器直接可用
