# 雅思词汇随身本

单文件离线复习工具 · IELTS Vocab

把词汇按 22 个主题章节整理成浏览器中的复习页。成品 `ielts-vocab.html` 内嵌数据与样式，无需安装依赖或启动后端。

## 使用

下载后直接打开 `ielts-vocab.html`。macOS 也可执行：

```bash
open ielts-vocab.html
```

页面支持按章浏览、词义对照、学习进度、复习记录和数据导出。本地进度保存在当前浏览器，清除浏览器数据会影响记录；切换设备不会自动同步。

## 内容生成流程

| 文件 | 作用 |
| --- | --- |
| `parse_vocab.py` | 从原始词汇材料提取结构化数据 |
| `build_vocab_app.py` | 生成词汇数据文件 |
| `vocab_data.js` | 生成后的词汇数据 |
| `generate_html.py` | 将数据、样式与交互组合成单文件页面 |
| `ielts-vocab.html` | 可直接使用的复习成品 |

先通过 Python 处理内容，再生成可离线使用的页面，是本项目的主要实践。生成脚本保留初始工作目录中的绝对路径，重新构建前需要按本机目录调整，不能直接视为通用的一键构建流程。

## 内容与运行边界

词汇依据《雅思词汇真经》（刘洪波）整理，用于个人学习。第三方词条解释与原始资料的权利仍归相应权利人，复用或再分发时应核对授权范围。

页面的发音能力依赖浏览器语音引擎和设备语音包，离线可用性随设备而异；本地词汇浏览与复习记录不依赖服务器。项目采用 AI 辅助整理与开发。
